# OpenSwitch 产品需求文档（PRD）

## 1. 背景与问题

在 macOS 中，文件默认打开方式通常通过 Finder 的「显示简介」进行修改。  
该方式对单类型可用，但在以下场景效率较低：

- 需要频繁在多个编辑器间切换
- 需要对多个扩展名统一切换
- 需要周期性在固定规则间来回切换

OpenSwitch 的目标是将上述操作流程化、批量化与可复用化。

## 2. 产品目标

- 将默认应用切换操作控制在秒级
- 支持单个与批量扩展名切换
- 支持预设化与一键回放
- 保证操作结果可见、可回滚

## 3. 用户场景

### 场景 A：单扩展名快速切换

- 触发：临时将 `.md` 从编辑器 A 切换到编辑器 B
- 操作：选择扩展名 -> 选择应用 -> 应用
- 结果：系统默认打开方式立即生效

### 场景 B：批量扩展名统一切换

- 触发：将 `.md`、`.txt`、`.json` 统一切换到同一应用
- 操作：多选扩展名 -> 选择应用 -> 应用
- 结果：多个类型一次完成切换

### 场景 C：预设一键切换

- 触发：在「开发模式」「写作模式」间切换
- 操作：选择预设 -> 一键应用
- 结果：预定义扩展名集合按规则批量切换

## 4. 功能需求（MVP）

### FR-1 扩展名输入与校验

- 支持输入 `md` 或 `.md`（内部统一标准化）
- 去重、过滤空值、非法字符提示

### FR-2 应用选择

- 显示系统已安装应用列表
- 支持按应用名搜索

### FR-3 单扩展名切换

- 对单个扩展名设置默认应用
- 成功后反馈结果

### FR-4 批量扩展名切换

- 对多个扩展名应用同一目标应用
- 显示成功/失败明细

### FR-5 预设管理

- 新建预设：名称、扩展名列表、目标应用
- 编辑/删除预设
- 一键应用预设

### FR-6 最近操作回滚

- 记录上一次批量切换前的映射
- 支持一次快速回滚

## 5. 非功能需求

- 兼容 macOS 主流版本（后续定义最低支持版本）
- 本地离线可用，无账号依赖
- 响应时间短，批量切换结果可视化

## 6. 技术约束

- 系统接口：LaunchServices
- 类型标识：UniformTypeIdentifiers
- 本地存储：Application Support 下本地文件

## 7. 里程碑

### M1：最小闭环

- 完成单扩展名切换
- 完成批量扩展名切换
- 完成基础结果反馈

### M2：可复用能力

- 预设管理
- 一键应用预设
- 最近操作回滚

### M3：可发布能力

- 错误处理与边界覆盖
- 文档完善
- 开源发布准备

## 8. 验收标准（MVP）

- 可对单个扩展名成功设置默认应用
- 可对至少 3 个扩展名进行一次批量设置
- 预设创建后可重复应用
- 最近一次批量操作可回滚
